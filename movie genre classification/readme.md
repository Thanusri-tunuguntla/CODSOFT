# Movie Genre Classification

This project is developed as part of my Machine Learning Internship at CodSoft.

# Project Overview

The goal of this project is to build a Machine Learning model that can predict the genre of a movie based on its plot summary or description.

The model analyzes textual information from movie descriptions and classifies them into different genres such as Action, Comedy, Drama, Horror, Romance, Sci-Fi, Thriller, and more.

# Dataset Information

The dataset contains:
- Movie Title
- Genre
- Movie Description

Dataset files used:
- `train_data.txt`
- `test_data.txt`
- `test_data_solution.txt`

---

# Project Workflow

1. Load and preprocess dataset
2. Clean text data
3. Convert text into numerical vectors using TF-IDF
4. Split dataset into training and testing data
5. Train Logistic Regression model
6. Predict movie genres
7. Evaluate model accuracy
