# Spam SMS Detection 

This project is developed as part of my Machine Learning Internship at CodSoft.

# Project Objective
The goal of this project is to classify SMS messages as Spam or Ham using Machine Learning techniques.

# Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

# Machine Learning Algorithm
- Logistic Regression

# Features
- Data preprocessing
- TF-IDF vectorization
- Spam/Ham prediction
- Data visualization

# Accuracy
Achieved high accuracy on test dataset.
