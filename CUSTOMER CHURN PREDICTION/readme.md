# Customer Churn Prediction

This project is developed as part of my Machine Learning Internship at CodSoft.

## Project Objective

The objective of this project is to build a Machine Learning model that can predict whether a customer is likely to leave a company or continue using its services.

Customer churn prediction helps businesses improve customer retention and reduce losses.

---

- Python
- Pandas

- Matplotlib
- Scikit-learn

- Data Preprocessing
- Label Encoding
- Feature Scaling
- Classification
- Logistic Regression
- Train-Test Split

---

## Dataset Features

The dataset contains customer-related information such as:

- Credit Score
- Geography
- Gender
- Age
- Balance
- Number of Products
- Estimated Salary
- Churn Status

---

## Project Workflow

1. Load dataset
2. Data preprocessing and cleaning
3. Encode categorical values
4. Scale numerical features
5. Split training and testing data
6. Train Logistic Regression model
7. Predict customer churn
8. Evaluate model accuracy
